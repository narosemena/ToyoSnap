You are implementing Task 1 of the AI PII Scanner feature for ToyoSnap, a Manifest V3 Chrome extension.

## Your job
Update `src/manifest.ts` to add an options page and relax the CSP for AI API endpoints.

## Why
The extension currently has `connect-src 'self'` which blocks all external fetches. We are deliberately adding specific AI API endpoints to support the new opt-in AI PII scanner feature. This is documented in `docs/superpowers/specs/2026-05-06-ai-pii-scanner-design.md`.

## Exact change needed

Replace the ENTIRE contents of `src/manifest.ts` with the following:

```typescript
/**
 * ToyoSnap Manifest V3 Configuration
 * Enforces Zero-Egress isolation via strict Content Security Policy.
 * NOTE: connect-src includes AI API endpoints — deliberate opt-in for the AI PII scanner feature.

 */
export default {
  manifest_version: 3,
  name: "ToyoSnap",
  version: "0.1.0",
  description: "Zero-Egress WorkflowCapture Engine  -  browser extension for instructional designers",

    "16": "icons/icon16.png",
    "32": "icons/icon32.png",
    "48": "icons/icon48.png",
    "128": "icons/icon128.png",
  },
  permissions: ["storage", "activeTab", "scripting", "tabs"],
  host_permissions: ["<all_urls>"],
  action: {
    default_popup: "src/popup/popup.html",
    default_icon: {
      "16": "icons/icon16.png",
      "32": "icons/icon32.png",
      "48": "icons/icon48.png",
      "128": "icons/icon128.png",
    },
  },
  options_page: "src/options/options.html",

  },
  web_accessible_resources: [
    {
      resources: ["icons/*.png", "src/editor/editor.html", "src/welcome/welcome.html"],

    },
```
